# Plataforma Educativa

Aplicación móvil educativa desarrollada con React Native, TypeScript, Expo y Supabase. Gestiona estudiantes, asignaturas, calificaciones, tareas, tutorías y relaciones de colaboración aplicando listas enlazadas, pilas, colas, árboles binarios, tablas hash y grafos.

## Ejecución

```bash
npm install
npx expo start -c
```
