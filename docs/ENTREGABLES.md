## Conversión del documento técnico

El documento está en Markdown para conservar diagramas y facilitar su edición. Para entregar PDF, ábrelo en VS Code, GitHub o un editor Markdown y usa imprimir/exportar a PDF. También puedes pegarlo en Word y exportarlo como `.docx` o PDF.

Antes de entregar, reemplaza la sección de capturas con imágenes reales del demo.
